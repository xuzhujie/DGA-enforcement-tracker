首先：DGA 是什么？

《数据治理法》（Data Governance Act）是欧盟建立数据共享信任机制的横向法规，适用于 2023-09-24 起的相关机制。

公共部门数据

受保护数据再利用

为公共部门持有、受商业秘密、知识产权或统计保密保护的数据再利用设置条件。

数据中介

中立的数据共享服务

数据中介服务需遵守通知、名称和中立性等要求；公开登记数量与执法案件分开统计。

数据利他

自愿共享与 EDIB

支持数据利他组织登记，并设立 European Data Innovation Board（EDIB）协调相关治理。

Article 31：非个人数据国际访问 / 转移

对在欧盟持有的非个人数据，相关主体应采取合理的技术、法律和组织措施，防止与欧盟或成员国法律冲突的国际转移或政府访问；第三国命令通常还需国际协定或具体、必要、相称且可复核的条件。

范围与边界

主登记由人工核验；自动监测只产生待复核信号，不自动改写案件阶段或法律结论。

DGA implementation

记录欧委会对成员国主管机关指定/授权的 infringement 程序阶段。

Data intermediation

记录公共登记册中的 notified service entries，不能直接推导处罚或合规结论。

DMA / DSA 边界

DMA/DSA 的平台执法、罚款和程序不并入 DGA 主表；仅在交叉研究时另行关联。
